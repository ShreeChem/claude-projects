# Video Studio

Pipeline: Tella recording → HyperFrames composition (intro, captions, lower third, outro) → FFmpeg finish (Epidemic Sound music bed ducked under voice, -14 LUFS, thumbnail). Setup and user docs: `README.md`.

## Commands

```bash
npm run doctor                 # verify ffmpeg, HyperFrames, Tella key
npm run tella:list             # recent Tella videos (id, date, title)
npm run tella:pull -- latest   # or -- <videoId>; exports + downloads MP4, transcript, chapters; updates config
npm run build                  # config + footage + transcript → edit/index.html, output/<slug>.srt, -chapters.txt
npm run check                  # HyperFrames lint + runtime + layout checks on edit/
npm run render                 # → output/<slug>-picture.mp4   (append -- --quality draft for quick tests)
npm run finish                 # FFmpeg music mix + loudnorm + thumbnail → output/<slug>.mp4
npm run make                   # build + render + finish
```

## "Make a video from my Tella recording"

1. `npm run tella:pull -- latest` (or the id the user names).
2. Music: use the Epidemic Sound MCP tools if connected — `SearchRecordings` (mood/genre/BPM from the user's brief), then `DownloadRecording`; to fit a length use `EditRecording` → `PollEditRecordingJob` → `DownloadRecordingEdit`. Save the file into `media/music/` and set `"music"` in `config/video.json`. If the tools aren't connected, ask the user to drop an MP3 into `media/music/`. Ask the user to confirm the track before downloading.
3. `npm run make`, then report the files in `output/`.

## Reels (vertical 9:16 Shorts — "Life, Unsaid")

Photos + your recorded voiceover → captioned 9:16 reel with slow camera moves and a Life, Unsaid end card. One folder per reel: `reels/<name>/reel.json` (script lines per scene, image per scene, `voiceover`, `music`). Images live in `media/scenes/<name>/`, voiceovers in `media/voiceover/`.

```bash
npm run reel:build [-- <name>]      # reel.json → reel-edit/index.html + output/<slug>.srt
npm run reel:check                  # HyperFrames checks on reel-edit/
npm run reel:preview                # live preview
npm run reel:render [-- <name>]     # → output/<slug>-picture.mp4
npm run reel:finish [-- <name>]     # music mix + loudnorm + thumbnail → output/<slug>.mp4
npm run reel:make [-- <name>]       # all three (add --quality draft for a quick test)
```

- With no `voiceover`, scenes are timed from the script at `wordsPerSecond` (a silent draft). With one, the same proportions stretch to the recording's length.
- A scene with `"draft"` is a stand-in shot; `zoom` + `focus` [x%, y%] crop into a reused photo. `move` is `in`, `out`, `left` or `right`.
- Scene images: Canva `generate-image` (9:16) only returns thumbnails — place images full-bleed on 1080×1920 pages of a Canva design and `export-design` as JPG to get full size.
- The template is `template/reel.html`; `reel-edit/index.html` is generated.

## Rules

- Change the look in `template/composition.html`; `edit/index.html` is generated by `npm run build` and gets overwritten. After template edits run `npm run build` then `npm run check`.
- Keep each timed element in the template flat (only inline children like `<span>`), give it an `id`, and register animations on the single paused `window.__timelines["main"]` GSAP timeline — no `Math.random()`, `Date.now()` or network fetches in composition scripts.
- Music is mixed by `scripts/finish.mjs`, not in the composition — don't add `<audio>` music to the template or it will play twice.
- Music level/ducking tweaks only need `npm run finish`, not a re-render.
- Never print or commit `.env`.
