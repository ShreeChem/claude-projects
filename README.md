# claude-projects

Projects built with Claude Code for the **Life, Unsaid** YouTube Shorts & WhatsApp channel.

| Folder | What it is |
|---|---|
| [`video-studio/`](video-studio/) | Video pipeline: HyperFrames + GSAP compositions, FFmpeg finishing. Makes 16:9 videos from Tella recordings and 9:16 reels (`npm run reel:*`) from scene images + a recorded voiceover. See its [README](video-studio/README.md). |
| [`skills/life-unsaid-reels/`](skills/life-unsaid-reels/) | Claude skill that writes 60-second Life, Unsaid reel scripts (hook, body, call to action, scene-by-scene visual prompts) in English or Hindi-English. |
| [`react-bits-app/`](react-bits-app/) | Vite + React + Tailwind starter wired to the [React Bits](https://reactbits.dev) shadcn registry for animated components. |

Media files, renders, voiceovers, `node_modules` and `.env` files are not committed.
